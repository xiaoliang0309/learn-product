定时任务说明

定时任务是后端自动执行的，不需要人点，所以没有按钮。
学习项目里有一个 每分钟统计商户总数 的定时任务（@Scheduled）。
想看效果：打开后端控制台，每到「每分钟的第 0 秒」就会打印一行 【定时任务】每分钟统计商户总数: total=x

微服务远程调用（Nacos + Feign）

本页面是服务A（learning-mct-api, 9090）。点按钮后，服务A 不查自己的数据库， 而是通过 Feign 按服务名去 Nacos 找服务B（merchant-service-b, 9095），远程调用它拿数据。
链路：服务A → Feign → Nacos 查地址 → 服务B → 返回

验证降级（fallback）

把服务B 停掉（关掉它的进程），再点上面的按钮，会走 fallback 降级， 返回兜底提示「调用商户服务失败」，而不是直接报错——这就是微服务的容错。
